# Microsoft Purview

Microsoft's data security and compliance family: DLP, information protection (sensitivity labels), retention, eDiscovery, audit and communication compliance.

| Tier | Copilot-relevant capability |
|---|---|
| [[office-365-e1-plus]] | DLP for email and files; standard audit |
| [[microsoft-365-e3]] | + manual sensitivity labels (MIP P1), label inheritance in Copilot output, standard eDiscovery and retention |
| M365 E5 | + automatic labelling, endpoint and Teams DLP, premium eDiscovery and audit, communication compliance, DKE, trainable classifiers |

**Labelling rule:** **manual** sensitivity labelling = AIP / MIP **Plan 1** (M365 E3). **Automatic** labelling = AIP **Plan 2** (M365 E5). Confirmed by Jaspreet (SME), 2026-10-19.
