# Microsoft Defender for Endpoint

Microsoft's endpoint security platform. **Plan 1** ships in [[microsoft-365-e3]] as an ME3-only feature.

**P1 capabilities (per source):** attack surface reduction, web protection and filtering, device control (USB), centralised AV management.

- **Pairs with:** [[microsoft-intune]] for device management.

**Copilot role (M365 E3):** antimalware, web and network protection, and manual blocking of discovered risky AI apps on [[windows-11-enterprise]] devices. M365 E5 moves this to XDR ([[copilot-security-readiness]]).
