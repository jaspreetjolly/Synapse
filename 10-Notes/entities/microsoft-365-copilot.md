# Microsoft 365 Copilot

An AI assistant that combines LLMs with the user's data in Microsoft Graph and works inside the M365 apps, **within the Microsoft 365 compliance boundary**.

- **Licensing:** an add-on to Office 365 E1–E5 and Microsoft 365 E3/E5. The base plan determines which security and compliance controls apply ([[copilot-security-readiness]]).
- **Permissions:** Copilot only accesses data the user already has permission to view, so oversharing becomes visible. Interactions are logged for audit.
- **Distinct from:** Microsoft Copilot (free web chat) with [[enterprise-data-protection]], which is included with E1 Plus.
- **Price and scope** (L100 notes): $30 per user per month. Users toggle between "web" (Copilot Chat) and "work" (Graph-grounded) scope. 1,000+ plugins and connectors. Copilot Chat agents can be metered (pay as you go).
- **Hardware:** [[copilot-plus-pc]]
- **Prepare with:** [[zero-trust]] controls; roll out web-grounded prompts first, then Graph-grounded ([[copilot-security-readiness]]).
