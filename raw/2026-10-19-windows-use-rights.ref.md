# Addendum — Windows Enterprise use rights

Target pages: [[windows-virtualization-rights]] · [[windows-11-enterprise]] · [[microsoft-365-e3]]

## Verified facts
- Windows 11 Enterprise E3 and E5 are per-user subscriptions sold only via commercial licensing (incl. CSP) and require Windows Pro as the qualifying OS. — https://learn.microsoft.com/en-us/windows/whats-new/windows-licensing (last updated 2026-05-27)
- The overview lists "five Windows instances per licensed user" as an Enterprise use right, illustrated as a laptop plus a Cloud PC plus a specialized LTSC device, etc. — same URL
- Listed included rights also cover Azure Virtual Desktop, Windows 365 Enterprise and VDA access rights (with FSLogix), 36-month support for annual feature releases, Windows LTSC Enterprise, MDOP, and release-health/readiness reports. — same URL
- Windows Enterprise E3 delivered through Microsoft 365 F3 excludes MDOP, Windows LTSC Enterprise and Windows Autopatch. — same URL
- E5 adds Microsoft Defender for Endpoint Plan 2 on top of E3. — same URL
- Product Terms: users with Entra ID-based activation may activate Windows in the physical OS on up to **five concurrent devices**. — https://www.microsoft.com/licensing/terms/productoffering/WindowsDesktopOperatingSystem/EAEAS
- Product Terms: per-user licensing requires the licensed user to be primary user of at least one primary work device licensed with a qualifying OS. — same URL
- Product Terms: users with M365 E3/E5/F3/Business Premium/A3/A5, Windows Enterprise E3/E5, Education A3/A5 or VDA E3/E5 may access AVD Windows VMs, and **AVD VMs don't count toward the activation device limit**. — same URL
- Product Terms (SA/subscription rights): up to four local virtual OSEs per licensed device/user, and remote access to up to four virtual OSEs or one physical OSE. — same URL
- Product Terms: Windows Enterprise per-user users may run Windows 11 VMs in their own Azure accounts, accessing up to four instances. — same URL
- Windows VDA (per device or per user) licenses access to virtual desktops from devices without qualifying Enterprise/VDA rights, e.g., thin clients. — https://learn.microsoft.com/en-us/windows/whats-new/windows-licensing
