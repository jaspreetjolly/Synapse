# Addendum — Universal Print licensing

Target page: [[universal-print]]

## Verified facts
- Universal Print entitlement is bundled in commercial, education and government Microsoft 365 and Windows Enterprise subscriptions, and is also sold standalone. — https://learn.microsoft.com/en-us/universal-print/get-access-to-universal-print (last updated 2025-07-21)
- Eligible commercial licences: Microsoft 365 E3/E5/F3, Windows 10/11 Enterprise E3/E5, Microsoft 365 Business Premium, Universal Print standalone; education: Microsoft 365 A3/A5, Windows Enterprise A3/A5. — same URL
- Both end users who print and admins who manage printing need an eligible licence. — same URL
- Usage is metered in print jobs, not pages, users or printers; one document = one job regardless of pages, copies, duplex or colour. — same URL
- Each eligible licence contributes jobs to a single tenant-wide pool that all licensed users share; the pool refreshes monthly, and no user is capped at their own licence's contribution. — same URL
- Monthly jobs contributed per licence: Microsoft 365 E3/E5/Business Premium = 100; Microsoft 365 F3 = 5; Windows Enterprise E3/E5 = 5; Universal Print standalone = 5; Microsoft 365 A3/A5 (paid) = 100; Windows Enterprise A3/A5 = 5. — same URL
- Student Use Benefit licences add no jobs to the pool. — same URL
- A job is counted only when delivered to the printer or acquired by a third-party service (counted even if never released via badge); service-side failures are not counted. — same URL
- Over-use doesn't stop printing; the admin is alerted and is expected to buy add-ons/licences to stay compliant. — same URL
- Volume add-ons: 500 jobs (~$25/month list) and 10,000 jobs (~$300/month list), monthly billing on annual commitment, EDU discounts available; prices subject to change. — same URL
- Product Terms list Universal Print Volume Add-ons as requiring an M365 A3/A5/E3/E5/F3/E7, Business Premium, Windows 11 Enterprise E3/E5, Education A3/A5 or Universal Print licence. — https://www.microsoft.com/licensing/terms/productoffering/WindowsDesktopOperatingSystem/EAEAS
- Universal Print is listed as a Windows Enterprise cloud capability that also works on Windows Pro devices. — https://learn.microsoft.com/en-us/windows/whats-new/windows-licensing
